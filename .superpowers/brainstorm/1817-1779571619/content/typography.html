A. 衬线中文标题 + 竖排装饰

标题用宋体/明体 (serif)，笔画有书法韵味。学科名竖排展示，像古籍目录。正文保持系统无衬线保证可读性。加载 Noto Serif SC（~2MB，CDN 缓存）。

优点

  • 中文书法感强，匹配语文/古文气质
  • 竖排学科名独特，一眼记住
  • 免费 Google Font

缺点

  • 2MB 字体文件，首屏加载需优化
  • 宋体在暗色背景下小字号可读性一般

B. 几何现代体 + 混字重

标题用几何感无衬线（系统黑体 bold），与英文斜体细体混排形成对比——"探索"用 900 粗体，"Universe"用 300 细斜体。同一行内字重对比本身就很"设计感"。学科标签用竖排等宽字体。零额外字体下载。

优点

  • 零额外加载，首屏即显
  • 字重对比 + 底线装饰足够有设计感
  • 暗色背景下中英文混排层次清晰

缺点

  • 仍然依赖系统字体，不同平台表现有差异
  • 不如专用字体统一

C. 渐隐水墨风 + 繁体装饰

标题用渐变色 (gradient text)——每个字从上到下从白渐变到对应学科色，像水墨晕染。学科名用繁体汉字（語/數/英/理/化），底部一行古语做装饰文字。仅用 CSS gradient + 字距，零额外字体。

优点

  • 渐变文字视觉冲击力一眼记住
  • 繁体字 + 古语增加文化质感
  • 零额外字体加载，纯CSS实现

缺点

  • 渐变文字对小学生可能稍显"高冷"
  • 繁体字部分学生可能不认识
